| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | Starter ที่รวมไลบรารีพื้นฐานสำหรับการทดสอบ เช่น JUnit Jupiter, AssertJ, Mockito และ Spring Test จึงไม่ต้องเพิ่มแต่ละตัวแยกกัน โดยโครงการนี้ใช้ Spring Boot parent จัดการรุ่นของ dependency ให้ |

| spring-test | เครื่องมือทดสอบของ Spring Framework เช่น การจัดการ Spring context ระหว่างการทดสอบ และ MockMvc สำหรับทดสอบ Spring MVC controller โดยไม่ต้องเปิด HTTP server จริง |
| hamcrest | ไลบรารีสำหรับสร้าง matcher เพื่อตรวจสอบเงื่อนไขของผลลัพธ์ เช่น `assertThat(x, is(3))` เป็นอีกแนวทางหนึ่งในการเขียน assertion |
